# 快速入门指南

欢迎使用 OmniTerminal！

## 1. 安装

- **macOS**：下载 `OmniTerminal-macos-arm64.dmg`（Apple Silicon）或 `OmniTerminal-macos-intel.dmg`（Intel），双击拖入 `Applications` 目录。
- **Windows**：下载 `OmniTerminal-windows-amd64.zip`，解压后双击 `OmniTerminal.exe` 即可运行。
- **Linux**：解压 `OmniTerminal-linux-amd64.tar.gz`，赋予可执行权限后运行。

## 2. 建立首次连接

在顶栏 **Omnibar** 搜索框中直接输入：
```bash
ssh://root@192.168.1.100:22
```
按下回车即可免建会话快速直连。
