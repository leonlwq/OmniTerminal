# OmniTerminal v1.0.1 发行说明

OmniTerminal v1.0.1 带来多项高生产力特性与稳定性升级：

## 核心新特性

- **高保真终端打印与导出引擎**：
  - 支持多范围提取（当前可视屏幕 / 完整滚动缓冲区 / 选中文本）；
  - 提供 Clean Paper（省墨白底）与 Dark Geek（极客暗黑）双模式；
  - 支持行号切换、页眉时间戳水印微调与 1:1 仿真 A4 纸张实时预览；
  - 双通道无阻塞物理打印链路（前端隐藏 iframe 打印 + 操作系统原生打印管道）；
  - 支持一键导出打印级 HTML / PDF 与复制格式化文本。

- **容器探索抽屉自适应排版 (Adaptive Flex Layout)**：
  - 彻底重构容器抽屉为标准流式布局，展开与调整宽度时终端视口自动实时重排行列字符，彻底杜绝内容被浮层遮挡；
  - 边缘拖拽调整宽度（240px ~ 900px）支持双击一键恢复默认并自动持久化。

- **多层级容器与微服务探测引擎**：
  - 自动注入系统完整 PATH，支持远程无感免密提权（`sudo -n`）与 Podman 兼容执行；
  - 「灵活 JSON -> 标准制表符 TSV -> 原生终端表格」三级格式容错解析。

- **会话侧栏连通性探测与交互优化**：
  - 折叠目录级联状态感知（绿/黄/红指示灯与在线/总数计数徽标）；
  - 优化把手拖拽释放事件捕获，彻底避免指示线状态卡死。
