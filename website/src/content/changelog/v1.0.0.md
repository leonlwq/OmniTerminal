# OmniTerminal v1.0.0 发行说明

OmniTerminal v1.0.0 为首个全平台稳定发行版，主要特性与系统更新如下：

## 核心特性

- **跨平台桌面客户端**：原生支持 macOS (Apple Silicon & Intel)、Windows (x64 & ARM64) 以及 Linux (x86_64)。
- **侧边抽屉式 SFTP 传输**：与当前终端会话路径实时联动，支持并发分片传输、断点续传与权限配置。
- **本地主密码加密 (Zero-Plaintext)**：会话凭据（密码、私钥、TOTP）均通过 PBKDF2 派生密钥执行 AES-256-GCM 加密存储，支持闲置超时自动锁屏。
- **WebGL 硬件加速渲染**：基于 xterm.js WebGL 渲染管线与 Go 后端 10ms 批处理窗口，保障高吞吐日志输出流控。
- **多终端视口同步滚动**：水平与垂直分屏模式下支持基于视口比例的同步滚动，便于多节点比对排障。
