# OmniTerminal v1.0.0 发行说明

我们非常自豪地宣布 **OmniTerminal v1.0.0** 正式发布！

## 🚀 核心特性

- **现代一体化工作台**：告别传统古早拟物灰调，以 VS Code Dark Modern 现代工程美学重塑终端体验。
- **全平台原生支持**：支持 macOS (Apple Silicon & Intel) DMG/ZIP、Windows x64/ARM64 绿色版与 Linux tar.gz。
- **双栏并排 SFTP**：终端右侧无缝滑出，支持并发传输队列、断点续传与权限修改。
- **AES-256 主密码金库**：所有密码与私钥本地高强度加密存盘，闲置自动锁屏保护。
- **WebGL GPU 渲染**：60 FPS 极速刷新，配备防丢包字符延时发送机制。
